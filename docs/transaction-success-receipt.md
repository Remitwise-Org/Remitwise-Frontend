# Transaction Success Receipt

> **Audience:** Contributors designing, implementing, or reviewing the post-send confirmation receipt on the Send Money page.
> **Goal:** Document the redesigned receipt layout, split breakdown visuals, copy/share interaction patterns, and responsive structure so reviewers can verify behaviour against the documented intent.

## Overview

After a send is confirmed via `POST /api/send`, the `TransactionSuccessReceipt` component renders as a full-screen modal overlay. The receipt is the user's trust moment — it confirms the transfer went through and provides the information needed to verify, share, or act on the transaction.

### Section rationale

| Section | Purpose |
|---------|---------|
| **Header** | Success icon + title set the emotional tone. Status indicator shows live polling confirmation. |
| **Amount + Recipient Hero** | The two most important pieces of info — what was sent and to whom — in a single scannable card. |
| **Split Breakdown** | Uses the shared `SPLIT_BUCKETS` config for icon/color/label consistency with the rest of the app. Bars show proportional allocation at a glance. |
| **Transaction Details** | Compact summary of date, fee, and hash. Hash has inline copy affordance. |
| **Explorer Link** | Network-aware link to Stellar.expert via `getExplorerTxUrl()`. |
| **Actions** | Share button uses native `navigator.share()` with clipboard fallback. Receipt button triggers `window.print()`. |
| **Navigation** | "Send Another Transfer" returns to the send form. "Return to Dashboard" navigates to `/dashboard`. |

## Copy / Share Interaction Patterns

### Transaction Hash Copy

```
[GABCDE...WXYZ] [📋]   → click   →   [GABCDE...WXYZ] [✅]
```

- **Idle state:** Shows truncated hash + Copy icon
- **Copied state:** Copy icon swaps to Check icon (`text-emerald-400`), resets after 2 seconds
- **Accessibility:** Button has `aria-label="Copy transaction hash"`. A `role="status"` live region announces "Transaction hash copied"
- **Button size:** Matches the text line height to keep the row compact; no background change on hover aside from the icon colour

### Share

```
[📤 Share]   → click   →   [✅ Link Copied] (2s)   →   [📤 Share]
```

- **Desktop (no `navigator.share`):** Copies `"Sent $1,250.00 USDC to Maria Santos via RemitWise\n<explorer_url>"` to clipboard. Button text changes to "Link Copied" with a Check icon for 2 seconds
- **Mobile (`navigator.share` available):** Opens the OS share sheet with title, text, and URL. No UI change needed — the OS handles feedback
- **Fallback safety:** `navigator.share()` is wrapped in try/catch to silently handle user dismissal
- **Accessibility:** A `role="status"` live region announces "Share link copied to clipboard" when the clipboard fallback fires

### Explorer Link

```
[ View on Stellar Explorer → ]
```

- Opens the transaction page on Stellar.expert in a new tab (`target="_blank"` with `rel="noopener noreferrer"`)
- URL is generated by the network-aware `getExplorerTxUrl(hash)` utility from `@/lib/utils/explorer`
- If `hash` is empty, the link is not rendered (the utility returns `null`)

## Split Breakdown Visuals

The split breakdown uses the shared `SPLIT_BUCKETS` config from `lib/config/split-buckets.ts`:

| Bucket | Icon | Bar Colour | Text Colour |
|--------|------|------------|-------------|
| Daily Spending | `ShoppingCart` | `bg-blue-300` | `text-blue-300` |
| Savings | `PiggyBank` | `bg-green-300` | `text-green-300` |
| Bills | `FileText` | `bg-amber-300` | `text-amber-300` |
| Insurance | `Shield` | `bg-violet-400` | `text-violet-400` |

Each row shows the icon, label, formatted amount, and a proportional bar (`width: ${(amount / total) * 100}%`). The "AUTOMATIC" badge uses the app's red accent token to match the send flow's split card.

## Responsive Layout

### Mobile (< 640px, single column)

```
┌────────────────────────┐
│  [X] close             │
│    ✅ Transfer OK      │
│  ┌─ AMOUNT ──────────┐│
│  │ $1,250.00 USDC    ││
│  │ To Maria ...WXYZ  ││
│  └───────────────────┘│
│  ┌─ SPLIT ───────────┐│
│  │ 4 rows stacked    ││
│  └───────────────────┘│
│  ┌─ DETAILS ─────────┐│
│  │ 3 compact rows    ││
│  └───────────────────┘│
│  [ Explorer ]         │
│  [Share] [Receipt]    │
│  [ ← Send Another ]   │
│  Dashboard →          │
└────────────────────────┘
```

- Modal uses `p-4` body padding (→ `p-6` on mobile to `sm:p-8` on desktop)
- Split bar width: `w-20` on mobile, `w-24` on `sm:` breakpoint
- Amount hero: `text-3xl` on mobile → `sm:text-4xl`
- All action buttons remain full-width of their grid cell
- Text never overflows — hash truncation keeps long strings in check

### Desktop (≥ 640px, centred modal)

```
┌────────────────────────────────────┐
│  Same layout, wider max-w-lg card │
│  Larger amount text, wider bars   │
│  Comfortable padding throughout   │
└────────────────────────────────────┘
```

- Max width: `max-w-lg` (32rem / 512px)
- Card is centred both horizontally and vertically with `inset-0 flex items-center justify-center`
- Scrolls vertically on short viewports (overflow is handled by the parent backdrop)

## Accessibility

| Requirement | Implementation |
|-------------|---------------|
| **Dialog role** | `role="dialog"`, `aria-modal="true"` on the card container |
| **Heading label** | `aria-labelledby="receipt-heading"` on dialog, `id="receipt-heading"` on the h2 |
| **Focus management** | `h2` has `tabIndex={-1}` and a `ref`; `useEffect` calls `.focus()` on mount to move keyboard focus into the receipt |
| **Copy buttons** | Each copy button has `aria-label` describing its action (e.g. "Copy transaction hash") |
| **Copy feedback** | `role="status" aria-live="polite"` announces "Transaction hash copied" / "Share link copied to clipboard" for screen readers |
| **Reduced motion** | All `animate-in` classes are gated by `usePrefersReducedMotion()` |
| **Colour contrast** | Text uses the app's standard gray/white palette on `#0A0A0A`; status tokens pass WCAG AA (§ 1.4.3) |
| **Print** | `PrintReceiptTemplate` is rendered alongside the visible receipt for `window.print()` support |
